# API Cinema - Filmes

Projeto acadêmico de uma API REST para gerenciamento de filmes e gêneros, desenvolvida em **Java** com **Spring Boot**, utilizando **Spring JDBC (JdbcTemplate)** para acesso a dados. Os testes das requisições foram realizados com o **Bruno**.

## Banco de dados

O projeto utiliza o **H2 Database**, um banco de dados relacional em memória, ideal para desenvolvimento e testes.

### Configuração (`application.properties`)

```properties
spring.application.name=api-cinema

spring.datasource.url=jdbc:h2:mem:db_cinema
spring.datasource.driver-class-name=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

spring.h2.console.enabled=true
spring.h2.console.path=/h2-console
```

Com o console habilitado, o banco pode ser acessado em:

```
http://localhost:8080/h2-console
```

Use como JDBC URL: `jdbc:h2:mem:db_cinema`, usuário `sa` e senha em branco.

```sql
    id_genero INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(50)
);
```

## Como rodar o projeto

1. Clone o repositório do projeto.
2. Certifique-se de ter o **JDK** instalado e configurado.
3. Abra o projeto na sua IDE de preferência (IntelliJ, Eclipse, VS Code, etc).
4. Verifique se o arquivo `application.properties` está com as configurações do H2 (ver seção [Banco de dados](#banco-de-dados)).
5. Rode a aplicação Spring Boot (classe principal com `@SpringBootApplication`), ou via terminal:

```bash
./mvnw spring-boot:run
```

6. A API estará disponível em:

```
http://localhost:8080
```

7. (Opcional) Acesse o console do H2 para visualizar o banco em `http://localhost:8080/h2-console`.

## Como testar (Bruno)

1. Instale o [Bruno](https://www.usebruno.com/).
2. Abra a coleção do projeto (`projeto-individual`) no Bruno.
3. Certifique-se de que a aplicação está rodando em `localhost:8080`.
4. Execute as requisições disponíveis na coleção:
   - **filmes**: cadastrar-filme, delete-por-id, listar-por-titulo, listar-todos, listar-por-id
   - **generos**: listar-generos
5. Verifique o corpo da resposta e o código de status retornado em cada requisição.

#### 2. Buscar filmes por título

- **Método:** `GET`
- **URL:** `/filmes/buscar/{titulo}`
- **Parâmetros de URL:**
  - `titulo` (String, path variable) — busca parcial e case-insensitive pelo título do filme
- **Respostas:**
  - `200 OK` — filme(s) encontrado(s)
  - `404 Not Found` — nenhum filme encontrado com o título informado

**Exemplo de requisição:**
```
GET http://localhost:8080/filmes/buscar/matar
```

**Exemplo de resposta (200):**
```json
[
  {
    "idFilme": 1,
    "titulo": "Duro de Matar",
    "descricao": "Um policial nova-iorquino enfrenta terroristas em um arranha-céu de Los Angeles.",
```

#### 4. Cadastrar filme

- **Método:** `POST`
- **URL:** `/filmes`
- **Formato da requisição:** JSON no corpo (`raw`)
- **Parâmetros do corpo:**

| Campo      | Tipo    | Obrigatório | Validações                                           |
|------------|---------|:-----------:|-------------------------------------------------------|
| titulo     | String  | Sim          | Não vazio, mínimo 3 caracteres, deve ser único        |
| descricao  | String  | Sim          | Não vazia, entre 3 e 150 caracteres                   |
| diretor    | String  | Sim          | Não vazio, entre 3 e 60 caracteres                    |
| url        | String  | Sim          | Não vazia, entre 3 e 250 caracteres                   |
| fkGenero   | Integer | Sim          | Deve corresponder a um `id_genero` existente          |

- **Respostas:**
  - `201 Created` — filme cadastrado com sucesso
  - `400 Bad Request` — algum campo inválido (título duplicado ou fora das regras, descrição, diretor, URL ou gênero inválidos)

**Exemplo de requisição:**
```
POST http://localhost:8080/filmes
Content-Type: application/json
```
```json
{
  "titulo": "Madagascar",
  "descricao": "Animais fogem de um zoológico e param em uma ilha",
  "diretor": "Caique",
  "url": "https://example.com/duro-de-matar.jpg",
  "fkGenero": 1
}
```

**Exemplo de resposta (201):**
```json
{
  "idFilme": 6,
  "titulo": "Madagascar",
  "descricao": "Animais fogem de um zoológico e param em uma ilha",
  "diretor": "Caique",
  "url": "https://example.com/duro-de-matar.jpg",
  "fkGenero": 1
}
```

**Exemplo de resposta (400):**
```
(sem corpo de resposta — indica falha em alguma regra de validação)
```

## Códigos de status

| Código | Significado           | Utilizado em                                                            |
|--------|------------------------|----------------------------------------------------------------------------|
| 200    | OK                     | Listagens e buscas bem-sucedidas (`GET /filmes`, `GET /filmes/{id}`, `GET /filmes/buscar/{titulo}`, `GET /generos`) |
| 201    | Created                | Cadastro de filme bem-sucedido (`POST /filmes`)                          |
| 204    | No Content             | Remoção de filme bem-sucedida (`DELETE /filmes/{id}`)                    |
| 400    | Bad Request            | Dados inválidos no cadastro de filme                                     |
| 404    | Not Found              | Filme não encontrado (por id, título ou ao tentar deletar)               |
