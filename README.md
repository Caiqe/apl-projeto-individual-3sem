## 📖 Sobre

O **APL - Cinema** é um projeto individual desenvolvido para as disciplinas de Programação Web (back-end) e Front-end (React), permitindo cadastrar, listar e remover filmes, com dados persistidos em banco de dados e consumidos em tempo real pela interface.

## 📂 Estrutura do repositório

| Diretório | Descrição | README |
|---|---|---|
| [`api-cinema`](./api-cinema) | API REST em Java + Spring Boot, responsável pela persistência e regras de negócio | [Ver documentação →](./api-cinema/README.md) |
| [`apl-front-cinema`](./apl-front-cinema) | Aplicação front-end em React, responsável pela interface e consumo da API | [Ver documentação →](./apl-front-cinema/README.md) |

## 🚀 Como executar

1. Suba a API back-end primeiro (instruções detalhadas no [README do back-end](./api-cinema/README.md)) — ela roda em `http://localhost:8080`.
2. Em seguida, suba o front-end (instruções detalhadas no [README do front-end](./apl-front-cinema/README.md)) — ele roda em `http://localhost:5173` e já consome a API automaticamente.
